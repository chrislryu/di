## Read an overview or a full guide

Each repository overview is chapter 1 of a 15-page guide. Use **Browse all chapters** to choose a subsystem or follow its internals in order. Chapter navigation stays inside that repository; overview navigation continues along the newcomer path above.

Start with the repository map, then follow startup and one representative operation. The chapters explain the main owners and decisions with diagrams and short routes into source. Choose a subsystem when you need it; you do not need to read every chapter in order.

## How to read the source

Read a guide's purpose and map first, then follow its representative operation through the linked symbols. Each link pins a commit. Compare state ownership at every process or device boundary: a queue entry, a logical block identifier, and the actual tensor bytes are different things.

The architecture can be followed through source alone. Runtime examples state their hardware and setup requirements separately.
