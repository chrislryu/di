## From a customer problem to the code

A response should start quickly, stream smoothly, and remain affordable as demand grows. Those requirements lead from one model engine to scheduling, cached state, multiple GPUs, and eventually a network fabric. Learn the responsibilities one boundary at a time.

Start with a single request. Then follow the same ideas as the system distributes work and moves state between devices.
